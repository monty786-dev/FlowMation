⏺ Record a task

Press Record, work on any website, then edit the recorded steps in the Studio panel.

🎯 Pick data

Click any element. FlowBrowser groups similar items and tables so you can extract them.

📊 Excel in, Excel out

Fill forms from Excel rows and write extracted tables to a sheet or a given cell range.

🤖 CAPTCHAs

When a flow meets one it pauses so you can solve it, then carries on.
